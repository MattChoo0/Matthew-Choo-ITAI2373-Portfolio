Objective: Text Representation focuses on converting unstructured text into numerical features for machine learning pipelines. You will implement and compare traditional sparse models such as Bag of Words, TF-IDF, and N-grams alongside dense vector representations such as word embeddings.
Core Tasks: 
Implement Bag of Words (BOW) and TF-IDF from scratch.
Analyze N-grams and explore dense word embeddings.
Compare sparse vs. dense feature representations.
Build text classification pipelines and answer embedded reflection questions.
