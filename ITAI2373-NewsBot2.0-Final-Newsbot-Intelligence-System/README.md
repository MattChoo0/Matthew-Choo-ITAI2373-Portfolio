# NewsBot Intelligence System
### ITAI 2373 – NLP Final Project
**Team MAEL**

## Project Overview

For our Final project, we developed a NewsBot Intelligence System 2.0 that uses Natural Language Processing (NLP) and machine learning to analyze news articles.

Our goal was to combine the NLP techniques we learned in class into one working system. NewsBot 2.0 can automatically classify news articles, analyze sentiment, identify named entities, and examine grammatical patterns.

This system could be useful for news organizations and businesses that need to process large amounts of news content.

Our Newsbot 2.0 is based on Team MAEL's midterm project Newsbot 1.0
