Lab 04: Text Representation

Objective: Text Representation focuses on converting unstructured text into numerical features for machine learning pipelines. You will implement and compare traditional sparse models such as Bag of Words, TF-IDF, and N-grams alongside dense vector representations such as word embeddings. Core Tasks: Implement Bag of Words (BOW) and TF-IDF from scratch. Analyze N-grams and explore dense word embeddings. Compare sparse vs. dense feature representations. Build text classification pipelines and answer embedded reflection questions.

Lab 05: Part-of-Speech Tagging in the Real World

Objective Exploring Part-of-Speech (POS) tagging—assigning grammatical categories such as like nouns, verbs, and adjectives to words—and moving from foundational concepts to real-world applications like handling messy social media text and customer service transcripts. Key Learning Objectives are Applying POS tagging using NLTK and SpaCy libraries. Comparing tag sets like Penn Treebank and Universal Dependencies. Handling ambiguous words and informal, messy text. Applying POS tagging to analyze customer service transcripts for sentiment and urgency. Benchmarking performance such as speed and accuracy across taggers and creating custom data visualizations.

L07 Sentiment and Emotion Analysis in the Real World

Objective: The lab focuses on identifying and categorizing emotions, opinions, and attitudes in text and speech using rule-based methods, machine learning, and multimodal techniques.
