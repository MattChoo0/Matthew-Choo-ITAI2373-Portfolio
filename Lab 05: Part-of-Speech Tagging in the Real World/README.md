Objective
Exploring Part-of-Speech (POS) tagging—assigning grammatical categories such as like nouns, verbs, and adjectives to words—and moving from foundational concepts to real-world applications like handling messy social media text and customer service transcripts.
Key Learning Objectives are
Applying POS tagging using NLTK and SpaCy libraries.
Comparing tag sets like Penn Treebank and Universal Dependencies.
Handling ambiguous words and informal, messy text.
Applying POS tagging to analyze customer service transcripts for sentiment and urgency.
Benchmarking performance such as speed and accuracy across taggers and creating custom data visualizations.
